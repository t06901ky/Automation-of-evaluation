前週（月曜〜金曜）の COO 週次レポートを生成する。

## 手順

1. 以下のコマンドを実行してレポートを生成する：
   ```bash
   python main.py --weekly
   ```

2. 実行後、`output/` ディレクトリに生成された PDF と JSON のパスを確認して報告する。

3. JSON の内容を読み込み、以下のサマリーを日本語で出力する：
   - 対象者と評価期間
   - 総合スコアと各カテゴリ（a〜e）のスコア
   - 強み・改善点・来週の推奨アクション

## 注意

- `.env` または環境変数が設定されていない場合は `--dry-run` を付けて実行する
- エラーが出た場合は原因を調べて報告する
